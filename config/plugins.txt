# Omarchy shell plugins, installed with `omarchy plugin add <url> --yes`.
#
#   <git-url>                      install only
#   <git-url>  enable:<plugin-id>  install and place on the bar
#
# Installing does not put a widget on the bar. Bar layout stays yours to
# arrange (see README non-goals) and `omarchy plugin enable` writes shell.json,
# so enabling is opt-in per plugin via the explicit enable: marker.
